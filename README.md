# Python Practice

Pythonの基礎学習と開発環境の構築を記録するリポジトリです。

## 学習目的

- Pythonの基本文法を習得する
- Linux（WSL Ubuntu）での開発に慣れる
- Git・GitHubによるバージョン管理を習得する
- 将来的なWebアプリケーション・AI開発の基礎を身につける

## 開発環境

- OS：Windows 11 / WSL Ubuntu
- エディタ：Cursor
- 言語：Python 3.14
- 仮想環境：venv
- バージョン管理：Git / GitHub

## ファイル構成

- `hello.py`：Pythonの実行確認用プログラム
- `.gitignore`：Gitの管理対象から除外するファイルの設定

## 実行方法

仮想環境を有効にした後、以下を実行します。

```bash
python hello.py
```
